# AI-Image-Analysis-and-Trip-Recommendation
<div align="center">
</div>

An intelligent travel assistance application that uses AI-based image analysis to identify landscapes, landmarks, and travel preferences from uploaded images, and generates personalized trip recommendations accordingly. The system combines computer vision techniques with recommendation logic to suggest destinations, activities, and travel plans based on visual inputs and user interests.

The project focuses on creating a seamless and interactive travel planning experience by integrating image processing, data analysis, and personalized recommendation workflows into a single platform.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
